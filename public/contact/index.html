Email

Write to contact@exportframes.com. It reaches the person who builds this site. There is no autoresponder, no ticket number, and no promise of a fast reply — but mail is read.

What to include

The useful reports are short: which browser and version, which file type failed, and what the page said when it failed. The tool prints its own error text on the page for a file it cannot decode — that sentence is the most useful thing you can paste.

What this address is not for

  • Sending a video for someone else to process. The tool is local-only by design; there is no way to run it on your behalf.
  • Bulk or commercial licensing requests.
  • Advertising or link placements. Ads on this site are not for sale directly.
